# RISKY Set 🌟

Custom emoji sets designed for broad compatibility and suitable for use in a wide range of projects. Both includes animated renditions.

## Models 🥕

### Emoji ❤️‍🔥
A complete set of icons developed for clear readability at multiple sizes.
This model keeps consistent styling balanced forms and adaptable color use making it suitable for interfaces applications and general digital environments.

### Collaborative 🫐
A model created for people to send their own versions following the official style guide.
It supports community contributions adaptation and creative expansion while preserving the visual identity of the set.
